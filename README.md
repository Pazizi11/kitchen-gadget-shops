# Kitchen Gadget Shops

A full-stack e-commerce platform built to demonstrate practical backend and frontend development, payment integration, product management, and third-party fulfillment integration.

**Live website:** https://bykitchengadgetshops.com

## Technology Stack

### Backend
- Medusa.js 2.19
- Node.js and TypeScript
- PostgreSQL
- Redis

### Frontend
- HTML
- CSS
- JavaScript

### Integrations
- Stripe payment integration
- CJ Dropshipping fulfillment integration
- Google authentication

## Platform Features

- Product browsing and product detail pages
- Shopping cart and checkout
- Customer registration and authentication
- Stripe payment integration
- Order management
- Product review functionality
- Newsletter subscription management
- Customer support form
- Custom administrative interfaces
- Supplier fulfillment integration

## Architecture

The project uses a Medusa.js backend to manage commerce functionality and a custom storefront built with HTML, CSS, and JavaScript.

The backend communicates with PostgreSQL for persistent data storage and Redis for supporting application infrastructure.

Third-party integrations extend payment processing and supplier fulfillment capabilities.

## Repository Structure

- `backend/` — Medusa.js backend application
- `storefront/` — Customer-facing storefront and administrative interfaces

## Security

Environment files, credentials, database exports, dependencies, operational scripts, and historical backups are excluded from this public repository.

Production credentials must be supplied through environment variables.

## Project Status

This project is deployed and publicly accessible.

The repository contains a curated portfolio copy of the application source code. It does not contain production customer data or production credentials.
